Program ini digunakan untuk sistem peminjaman buku perpustakaan. Daftar buku disimpan dalam Tuple karena datanya tetap, sedangkan buku yang dipinjam disimpan dalam List karena bisa bertambah atau berkurang. Pengguna dapat memilih untuk meminjam buku, menghapus buku dari daftar pinjaman, atau selesai. Program juga mengecek apakah buku tersedia sebelum dipinjam.
